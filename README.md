# Elamathi N - Data Analyst Portfolio

A modern, responsive portfolio website built with Next.js, React, TypeScript, and Tailwind CSS. Showcases data analyst skills, professional experience, education, projects, and contact information.

## Technology Stack

- **Framework:** Next.js (with React 19)
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide React
- **Themes:** next-themes (Supporting System, Dark, and Light mode)
- **Deployment:** Vercel / Netlify

## Features

- **Hero Section:** Responsive introduction with a professional profile photo and key call-to-actions.
- **About Me:** Biography, objectives, and card grid showcasing core strengths.
- **Skills Grid:** Grouped competencies spanning Programming, Visualization, Databases, and Tools.
- **Projects Console:** Filterable dashboard showcasing Excel, Python, and SQL/BI projects.
- **Work Experience:** Chronological timeline showing internship experience.
- **Contact Panel:** Card grids for professional networks and forms with direct mail triggers.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
